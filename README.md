# Corporate Birthday Mailer

Рабочее название интерфейса: **Добрый день**.

Первый MVP:
- Docker/Portainer;
- веб-интерфейс на порту **8082**;
- PostgreSQL;
- локальный аварийный администратор;
- вход через Active Directory / LDAPS;
- получение XLSX-вложения по IMAP;
- отправка писем по SMTP;
- настройка IMAP, SMTP, AD и колонок XLSX через веб;
- чтение даты рождения вида `18, Май`;
- исключение работника при `Сотрудник.Скрыть день рождения (Сотрудники) = Да`;
- отдельное письмо на каждого именинника;
- защита от повторной успешной отправки в течение одного года;
- банк вступительных шаблонов с переменными;
- справочник `полная должность 1С -> короткая должность для поздравления`.

## Развертывание в Portainer

1. Скопируйте `.env.example` в `.env`.
2. Обязательно поменяйте `POSTGRES_PASSWORD`, `APP_SECRET_KEY` и `BOOTSTRAP_ADMIN_PASSWORD`.
3. Разверните `docker-compose.yml` как Stack.
4. Откройте `http://<docker-host>:8082`.
5. Войдите локальным `admin`.
6. Настройте IMAP, SMTP, AD и названия колонок XLSX.
7. Сначала импортируйте тестовый XLSX вручную и проверьте результат.
8. Автоматическая рассылка по умолчанию выключена.

### Почта

SMTP используется только для отправки. Для получения письма с XLSX-вложением используется IMAP.

### XLSX

Первая строка может быть пустой/объединенной. По умолчанию:
- заголовки: строки 2 и 3;
- данные: с 4-й строки.

Колонки ищутся по нормализованному названию, а не по номеру.
