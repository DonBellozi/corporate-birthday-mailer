# Зафиксированные правила MVP

- Один именинник = одно отдельное письмо.
- Получатель письма = общая группа рассылки.
- Работник должен присутствовать в последнем успешном XLSX.
- `Сотрудник.Скрыть день рождения (Сотрудники) = Да` полностью исключает поздравление.
- Дата рождения `18, Май` поддерживается.
- Первая строка XLSX может быть пустой/объединенной; заголовки по умолчанию 2–3, данные с 4.
- Короткие должности хранятся только в именительном падеже.
- Пол влияет на грамматику, HTML-цвета и в будущем на открытки/пожелания.
- Пожелания и открытки независимы и отключаемы.
- Вступительные тексты редактируются в админке и поддерживают переменные.
- Локальный admin остается аварийным входом; рабочий вход можно разрешить через AD/LDAPS.
